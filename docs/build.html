Agenda Navigator is open source. If you want one of these for a different conference, fill in the four boxes below and this page writes the instructions.

Hand them to Claude Code (or any coding agent) and it will clone the project, write an adapter for your programme, and hand back a site you can put on GitHub Pages. Nothing on this page is sent anywhere — it's a text template, filled in by your browser.

The instructions

Copy this and paste it into Claude Code, in an empty directory. It will ask you questions as it goes — the parts it can't work out from the programme alone.



  
What this will and won't do

  
It works when the programme has real text in it — a description per
  session, or a handful of paper titles. Semantic matching against bare titles produces a
  route that looks convincing and is close to arbitrary, so the instructions tell the agent
  to check that first and stop if it isn't there.

  
It works best when the programme has a public API or an export feed. If the site only
  renders HTML, the agent will write a scraper, and that is the part most likely to need
  your help. If the programme is behind a login, it can't be done — the whole tool works by
  shipping the programme to the visitor's browser.

  
Size matters too: the embeddings are about 768 bytes per session description or paper
  title, so a 3,000-session mega-conference produces a download nobody wants. The
  instructions cover what to do about that.


  
The deal

  
It's MIT
  licensed — take it, change it, sell it if you can. Two things asked for rather than
  required: keep a credit line in the footer of whatever you deploy, and send improvements
  back as a pull request. The matching engine took a lot of quiet failures to get right, and
  they're all written down in the repo so you don't have to repeat them.

  
Keep the downloaded profile in fraglet
  shape while you're at it. It's the reason a profile you wrote for one conference tool can
  be reused in the next one.
